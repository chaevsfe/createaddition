# Create Fly: Crafts & Additions (Unofficial Port)

Brings the electrical age to Create: generate, store and move energy with electric motors, alternators, wires, capacitors, tesla coils and accumulators.

> [!IMPORTANT]
> **This is an unofficial port.** It is not affiliated with or endorsed by
> MRH0. 
> Please report problems here.

## Compatibility

| Component | Version |
| --- | --- |
| Minecraft | `26.2` |
| Mod loader | Fabric Loader `0.19.3` or newer |
| Create Fly | `6.0.9-1` or newer |
| Fabric API | required |
| Java | `25` or newer |
| Environments | Client and server |

## Download

- [Modrinth](https://modrinth.com/project/7bkhocI9)
- [GitHub releases](https://github.com/chaevsfe/createaddition/releases)


## Building

```
git clone https://github.com/chaevsfe/createaddition
cd createaddition
./gradlew build
```

Requires JDK 25.
